# Game Compatibility

Compatibility is still experimental. The results below describe the exact
scenario that has been verified and do not imply complete gameplay support.

| Game | Status | Verified behavior |
|------|--------|-------------------|
| `7day.app` | Partial | The startup logo renders correctly in standalone screenshot mode. |
| `AliBaba.app` | Partial | The startup title screen renders correctly in standalone screenshot mode. |
| `Astro-Lander.app` | Partial | The startup splash screen renders correctly with its external image and font assets in standalone screenshot mode. |
