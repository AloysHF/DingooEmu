DingooEmu

A Dingoo A320 handheld emulator written in Rust

🚧 开发中，敬请期待 🚧

Emulating the Dingoo A320 handheld game console powered by Ingenic JZ4740 MIPS SoC.
Supports real-time CPU scheduling, framebuffer rendering, Dingoo SDK HLE, and PCM audio output.
模拟搭载 Ingenic JZ4740 MIPS SoC 的 Dingoo A320 掌上游戏机，支持实时 CPU 调度、画面渲染、SDK 高层模拟和 PCM 音频输出。
